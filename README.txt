PÁGINA DE QUÍMICA

Arquivo principal:
- index.html

Pastas disponíveis para organizar futuros arquivos:
- assets/images  -> imagens, mockups e screenshots
- assets/css     -> estilos externos, se você quiser separar o CSS depois
- assets/js      -> scripts externos, se você quiser separar o JavaScript depois

Como abrir:
1. Abra a pasta.
2. Dê dois cliques em index.html para visualizar no navegador.
3. Para publicar, envie todo o conteúdo desta pasta ao seu serviço de hospedagem.

Observação:
O código HTML original foi mantido intacto e apenas renomeado para index.html.
